### 🛑 Use of eval() for user input

API key source code mein hardcode ki gayi hai. Agar repo public ho ya log access karein, toh secret expose ho jayega. Isse unauthorized access ho sakta hai.

`app/db.py:17` · medium

`except:` bina kisi specific exception ke use kiya gaya hai. Isse real errors (jaise database connection loss) silently fail ho jayenge, debugging mushkil ho jayegi.

**Suggestion:** Specific exception catch karo, jaise `except sqlite3.Error as e:`, aur logging add karo.
