### [CRITICAL] SQL Injection Vulnerability

यहाँ `name` पैरामीटर को सीधे SQL स्ट्रिंग में जोड़ा गया है, जिससे SQL Injection हमला संभव है। हमलावर `name` में विशेष अक्षर डालकर डेटाबेस को हानि पहुँचा सकते हैं या संवेदनशील डेटा निकाल सकते हैं।

### [CRITICAL] Use of eval()
`web/calc.js:4`

`eval()` का उपयोग गतिशील कोड निष्पादन के लिए खतरनाक है और Remote Code Execution (RCE) हमलों को सक्षम बनाता है। यह सुरक्षा का गंभीर जोखिम है।

**Suggestion:** `eval()` का उपयोग न करें। यदि गणितीय अभिव्यक्ति का मूल्यांकन करना है, तो एक सुरक्षित parser या library जैसे `mathjs` का उपयोग करें।

### [HIGH] Bare Except Clause
`app/db.py:19`

`except:` का उपयोग सभी exceptions को चुपचाप निगल देता है, जिससे डिबगिंग कठिन हो जाती है और असली त्रुटियाँ छिप जाती हैं।

**Suggestion:** विशिष्ट exception को पकड़ें, जैसे `except sqlite3.Error as e:` और तब लॉग करें या उपयुक्त त्रुटि संदेश लौटाएँ।

### [MEDIUM] Hardcoded API Key
